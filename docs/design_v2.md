# 文字修仙 · 玩法设计文档 v2（挂机养老版）

## 定位与核心理念

```
定位：挂机养老 · 纯文字 · 无寿元压力 · 失败温和 · 节奏从容
口号：「法无止境，仙是修不完的」——飞升不是终点，而是新起点。
```

| 关键词 | 设计体现 |
|---|---|
| 挂机 | 离线收益为主力，被动周天在线静默运行，一键托管可选 |
| 养老 | 无寿元压力，无赛季重置，无排名掉段惩罚，无绝版内容 |
| 不氪 | 不卖任何数值，氪金只买便捷与外观，数值天花板完全一致 |
| 不肝 | 日常任务 1-2 小时完成，全部可跳过，不做没有任何损失 |
| 温和 | 突破失败只散部分修为不掉境界，战斗有护持保底不死 |
| 长久 | 境界可无限扩展，事件/任务可持续新增，无终局 |

**设计红线**：
- 氪金玩家与免费玩家在数值上限上完全一致
- 日常奖励不具有排他性，跳过无惩罚
- 所有概率、速率、加成都设软上限，防止指数失控
- 主动操作是「调味料」，挂机收益才是「主菜」

## 一、核心循环：修炼主线

### 1. 境界体系（十八境 · 数据驱动）

| 阶段 | 境界序列 | 细分 |
|---|---|---|
| 凡界九境 | 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 | 炼气9层，渡劫3层，其余初期~圆满 |
| 仙界九境 | 人仙 → 地仙 → 天仙 → 玄仙 → 金仙 → 太乙 → 大罗 → 准圣 → 混元 | 各4层 |

- 飞升：渡劫圆满后直接晋升人仙，无分支，境界体系完全数据驱动（realms.py 可无限扩展）
- 专属铭文：每个大境界突破时呈现独特铭文文案
- 神通：金丹起每境解锁一项纯增益神通（炼丹/修炼/渡劫/突破加成）

### 2. 收益时钟（重构后 · 挂机核心）

**设计原则**：离线收益 ≥ 被动挂机 > 主动打坐 > 手动操作

| 收益来源 | 效率 | 消耗 | 说明 |
|---|---|---|---|
| 离线收益 | 需求 × 0.12% / 现实小时 | 无 | 基础值，读档自动结算 |
| 离线加成 | × (1 + 总加成 × 50%) | 无 | 所有加成对离线只生效一半 |
| 被动周天 | 主动打坐 × 60% | 无 | 仅在线时生效，静默无日志 |
| 主动打坐 | 需求 × 0.2% / 时辰 × 悟性 × 灵气 × 神通 | 精力 1.5/时辰 | 在线手动 |
| 闭关挂机 | 与主动打坐完全一致 | 精力 1.5/时辰 | 自动打坐-休息循环 |
| 现实时钟 | 在线 1.5 倍打坐速率 | 无 | Web 版每 30 秒自动刷新 |
| 顿悟 | 当前层需求 × 8%（凡界）/ 12%（仙界） | 无 | 打坐中自动判定 |

**互斥规则（重要）**：
```
离线期间 → 只结算离线收益
在线时   → 被动周天 + 现实时钟同时运行，但两者不叠加（取高者）
主动打坐/闭关 → 暂停被动周天，改结算主动收益
战斗/探索/炼丹等操作期间 → 被动周天继续运行（静默）
```
简化理解：任何情况下，同一时刻只有一种主收益在结算。

**顿悟判定**：
```
条件：打坐/闭关/被动周天中
频率：每 4 时辰判定一次
概率：clamp(5% + 气运/1000, 2%, 15%)
收益：当前层需求 × 8%（凡界）/ 12%（仙界）
```

**待领池规则（防跳级）**：
```
上限 = 当前境界本层需求的 100%
超出部分按 30% 自动转化为灵石
领取后若超过当前层需求，超出部分衰减为 30%
```

**一键托管（可选功能）**：`idle-auto on / off`
自动循环：打坐 → 精力不足自动休息 → 精力恢复后继续；修为圆满时自动停止，等待玩家手动突破；不会自动突破/嗑药/换装备/接任务。
定位：让玩家上班/睡觉时也能持续在线挂机，但所有决策权始终在玩家手中。

### 3. 精力系统（放宽版）

```
精力上限 = 100
恢复速度 = 2 / 时辰（在线离线均恢复）
```

| 操作 | 精力消耗 |
|---|---|
| 主动打坐/闭关 | 1.5 / 时辰 |
| 猎妖 | 8 / 次 |
| 论道 | 5 / 次 |
| 探索 | 10 / 次 |
| 炼丹 | 6 / 炉 |
| 秘境深入 | 12 / 层 |

- 精力离线也恢复，上线时大概率是满的
- 完成全部 7 项日常约消耗 40-50 精力，非常充裕
- 精力用完后，被动周天与离线收益不受影响
- 精力系统只限制主动操作频率，不限制挂机收益

### 4. 突破与劫难（温和失败）

**突破率公式**：
```
基础率 × (1 + 0.15%×(体质-10) + 0.10%×(悟性-10) + 0.05%×(气运-10))
 - 0.015%×丹毒 + 丹药加成 + 功法加成 + 师门指点
最终值 clamp(5%, 98%)
```

| 突破加成来源 | 上限 |
|---|---|
| 丹药加成 | +15pp |
| 功法加成 | +10pp |
| 师门指点 | +5pp |
| 所有来源合计 | +30pp |

**境界突破规则**：小境界修为圆满即可冲击（冷却 2 时辰）；大境界金丹起先渡天劫，劫过方可突破（冷却 6 时辰）。

**劫难体系（数据驱动）**：天劫（凡界大境界突破）/ 仙劫（仙界大境界突破）/ 天衰之劫（玄仙起）/ 道心劫（金仙起）/ 斩三尸（大罗起）/ 合道大劫（准圣→混元）。

**心魔劫**（跨大境界后 30% 概率触发），三选一，无绝对对错：
| 选项 | 效果 | 定位 |
|---|---|---|
| 正道 | 稳重，小增益 | 稳妥路线 |
| 歧途 | 冒险，大增益 + 副作用 | 风险路线 |
| 随缘 | 随机结果，无偏斜 | 不逼决策 |

**失败反噬**：
- 仅散去当前层 20%~40% 的修为
- 获得轻伤状态（调息 4 时辰恢复）
- 绝不掉境界，且失败后获得少量突破率补偿（+2pp，可叠加至 +10pp）

## 二、成长系统

### 1. 属性面板
```
最终值 = (base + Σadd) × Πmul
```
| 类别 | 属性 | 用途 |
|---|---|---|
| 战斗四维 | 攻击 / 防御 / 身法 / 神识 | 猎妖、论道、天骄榜 |
| 天赋三维 | 悟性（修炼/突破）、体质（气血/突破）、气运（顿悟/机缘/突破） | 全局影响 |
| 负面计量 | 丹毒 | 压制突破率，可调息/清毒丹化解 |

### 2. 装备（六部位 · 纯属性）
兵器（攻击）/ 护甲（防御）/ 法宝（全属性）/ 靴（身法）/ 佩饰（神识）/ 腰带（体质）
- 穿脱即时生效，无强化/套装/耐久；丹炉占据法宝位（炼丹时自动切换）

### 3. 功法
**效果类型**：attr_add（随境界缩放）/ attr_mul / 修炼速率 / 突破率 / 灵石加成 / 悟道

**叠加规则**：attr_add 相加；attr_mul 偏移相加（防指数爆炸）；突破率取 max；速率类相加封顶 +60%；**修炼速率总加成软上限 +80%，超出部分每 1% 仅算 0.3%**

**装备与熟练度**：装备上限 2 件起、每 3 境界 +1、硬顶 5；熟练度每 200 点 1 级（满 5 级 ×1.15/级）；修习功法即得签名技能

**品阶预算**：黄 32 / 玄 90 / 地 240 / 天 260 / 仙 480

### 4. 技能（自动施法 · 策略预设）
- 四类：攻伐/疗伤/护体/回灵；消耗灵力比例，有冷却，有反噬
- 三策略：保守（最稳）/ 均衡（默认）/ 激进（有风险，护持保底不死）
- 三策略最终境界一致，差异只在战斗过程

## 三、资源与经济

### 1. 灵石流转
| 来源 | 去向 |
|---|---|
| 猎妖掉落（14~600/场） | 修习功法（200~上万灵石） |
| 坊市卖出 | 换购丹方 |
| 门派日俸（15~60） | 入门费（100~800） |
| 天骄榜俸禄（榜首 500/日） | 洞府购置/扩建 |
| 产业产出 | 产业增资 |
| 任务奖励 | 租灵室（50贡献） |

开局 200 灵石：足以买一本黄阶功法，但买不起兵器——开局即面临取舍。

### 2. 坊市（防套利修订版）
| 规则 | 设定 |
|---|---|
| 价格浮动 | 每日基准价 × [0.5, 1.8] |
| 卖出价 | 当前市价 × 0.6 |
| 交易次数 | 每日买入 3 次、卖出 3 次 |
| 价格反馈 | 大量买入推高价格，大量卖出压低价格 |
| 时间消耗 | 不耗游戏时间 |

防套利说明：每日限次 + 交易影响价格，使倒买倒卖无利可图。

### 3. 炼丹
流程：`dan gather [时辰]` → 采药（凶险处稀有材料概率高）；`dan learn <id>` → 换购丹方；`dan refine <id> [炉数]` → 开炉

| 品阶 | 药效 | 丹毒增加 |
|---|---|---|
| 下品 | 70% | +3 |
| 中品 | 100% | +2 |
| 上品 | 140% | +1 |

**丹毒管理**：调息 4 时辰消解 5 点；清毒丹消解 20 点（自身有冷却）。丹毒压制突破率 -0.015% × 丹毒值。每日限额丹药 8 颗/日。

## 四、修仙五要

| 要 | 系统 | 命令族 | 核心机制 |
|---|---|---|---|
| 法 | 功法 | art | 多件装备，数据驱动效果，熟练度升级 |
| 财 | 产业 | asset | 灵田/矿脉/丹铺/商队，每日产出，增资升级 |
| 侣 | 道侣 | companion | 4 位道友，双修换修为+情分，加成边际递减 |
| 地 | 洞府+地点 | estate / travel | 洞府修炼加成 +5%~+45%，地点灵气密度 1.0~3.0 |
| 师 | 门派+师长 | sect | 职位晋升，师长指点，灵室静修 |

**道侣加成（边际递减）**：第 1 位 100% / 第 2 位 60% / 第 3 位 30% / 第 4 位 15%；每位道侣加成 = 基础值 × 情分（0.5~1.0）× 边际递减系数

**门派（七大门派）**：青云宗 / 血煞门 / 药王谷（炼气期，100灵石）；天机阁 / 剑冢 / 万宝楼（筑基期，500~800灵石）
- 职位：外门 → 内门 → 真传 → 长老，修炼场地加成 +2% → +12%
- 门派贡献：每日自动获得（基础 5 + 职位加成），不需专门刷取
- 师长：3 位（突破/攻伐/灵石方向），拜师得稳定加成；`sect mentor` 请指点（贡献换一次性突破率 +5pp，每日一次）
- 灵室静修：50 贡献租 24 时辰，修炼 +30%（临时 Buff 有时效）

**洞府与产业（自动维护）**：
- 洞府：凡居 → 灵宅 → 洞府 → 灵府 → 洞天，修炼加成 +5% → +45%
- 产业：灵田/矿脉/丹铺/商队，每日产出灵石+材料
- 自动维护：维护费从产出中自动扣除，不足时自动暂停而非荒废，无需手动处理

## 五、战斗与挑战

### 1. 猎妖与论道
| 维度 | 猎妖 | 论道 |
|---|---|---|
| 判定方式 | 战斗数值 + 技能策略 | 悟性 + 神识对撼掷骰 |
| 产出 | 灵石/材料/装备 | 修为：胜 4% / 负 2% 需求 |
| 修为附带 | 约等于打坐 × 1.13 | — |
| 难度档位 | weak/normal/elite/boss | 同左 |
| 每日限额 | 5 场 | 5 场 |
| 精力消耗 | 8 / 次 | 5 / 次 |

战斗为回合制自动推演，技能按策略自动施放，护持保底不死。

### 2. 秘境（简化版）
落云秘境 3 层（炼气，冷却 3 日）/ 万兽深渊 5 层（筑基，冷却 5 日）/ 太虚洞天 7 层（金丹，冷却 7 日）
- dungeon enter/next/flee/abandon；战败退层但不死亡，进度可保留
- 简化：战斗过程可跳过（直接显示结果）；每层修为 ≈ 1.5% 需求

### 3. 天骄榜
- 10 位 NPC 天骄，玩家金丹后自动入榜（垫底）；`tianjiao fight <名次>` 挑战更高名次，胜则互换
- NPC 成长与玩家完全同步（属性按玩家属性 × power 系数等比缩放），差距永远可追
- 每日按名次发放俸禄（榜首 500 灵石 + 30% 需求修为，逐名递减）；每日限 3 战
- 无掉段惩罚：即使被挑战失败，也不会掉出已有名次之外

## 七、日常任务系统（1-2 小时完成）

设计原则：所有日常可跳过，不做没有任何损失。做了给额外奖励，奖励不具排他性。

| # | 任务 | 耗时 | 奖励 | 可跳过 |
|---|---|---|---|---|
| 1 | 领取离线收益 | 1分钟 | 离线修为入账 | 否（自动） |
| 2 | 打坐 2 时辰 | 按钮点击 | 正常修炼收益 | 可 |
| 3 | 猎妖 1 次 | 约5分钟 | 额外灵石×1.5 | 可 |
| 4 | 论道 1 次 | 约3分钟 | 额外修为+2% | 可 |
| 5 | 探索 1 次 | 约5分钟 | 机缘判定×2 | 可 |
| 6 | 炼丹 1 炉 | 约10分钟 | 成丹率+5% | 可 |
| 7 | 拜访道侣/师长 | 1次 | 情分/贡献+20% | 可 |

每日奖励（按完成数，不滚动不累积，当日清零）：3 项 = 额外修为 1%；5 项 = 3% + 随机材料袋；7 项 = 5% + 每日宝箱

标准日常流程建议（约 50 分钟）：上线领离线 → 打坐 → 猎妖 → 论道 → 探索 → 炼丹 → 拜访 → 看天骄榜 → 逛坊市 → 闭关挂机（idle-auto）

## 十、数值平衡与软上限

**百分比加成软上限**：
| 加成类型 | 软上限 | 超出处理 |
|---|---|---|
| 修炼速率 | +80% | 超出部分每 1% 仅算 0.3% |
| 突破率加成 | +30pp | 超出无效 |
| 顿悟概率 | 15% | 钳制上限 |
| 灵石产出 | +300% | 超出部分仅算 20% |
| 离线收益率 | 主动的 50% | 所有加成对离线只生效一半 |

**长期节奏目标**：
| 阶段 | 纯离线玩家 | 每日 1-2 小时在线 | 全手动 |

## 十三、新手节奏指南

1. 炼气期（1~5 天）：开局 200 灵石抉择 → 闭关为主 + explore 碰机缘 → 落云秘境 → 熟悉日常（可跳过）→ 突破筑基
2. 筑基~金丹（5~15 天）：选门派 → 采药炼丹 → 拜师租灵室 → 天骄榜入榜 → 突破金丹解锁神通
3. 元婴~渡劫（15~40 天）：洞府产业铺开（财地）→ 结交道侣（侣）→ 门派功法（法）→ 渡劫前嗑丹+请指点 → 飞升
4. 飞升之后：仙界每境 130~190 日（纯挂机节奏），仙劫名目递进，五要全面展开，挂机养老法无止境
