# 文字修仙 · 玩法全景总结

> 定位：**挂机养老文字修仙**。无寿元死亡压力，失败惩罚温和，数值节奏以挂机打坐为基准校准。
> 「法无止境，仙是修不完的」——飞升不是终点。

---

## 一、核心循环：修炼主线

### 1. 境界体系（十八境）

| 阶段 | 境界序列 | 层数 |
|---|---|---|
| 凡界九境 | 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 | 炼气 9 层，渡劫 3 层，其余初期~圆满 |
| 仙界九境（洪荒九阶） | 人仙 → 地仙 → 天仙 → 玄仙 → 金仙 → 太乙 → 大罗 → 准圣 → 混元 | 各 4 层 |

- **飞升** = 渡劫圆满突破，零特殊分支，直接进人仙——境界体系数据驱动（realms.py 追加即可继续延伸）
- 每个大境界有专属**铭文**（突破时呈现）与**神通**（金丹起，纯增益：炼丹/修炼/渡劫/突破加成）

### 2. 修炼途径（六条路，口径统一按「本层需求比例」）

| 途径 | 命令 | 收益 | 成本/限制 |
|---|---|---|---|
| 主动打坐 | `cultivate [时辰]` | 需求 × 0.2%/时 × 悟性 × 灵气密度 × 神通 | 耗精力 1.5/时 |
| 闭关挂机 | `idle [天数]` | 与手动打坐完全一致（自动打坐-休息循环） | 无参闭关至修为圆满自动停 |
| 被动周天 | 无需操作 | 主动打坐 × 60%（无顿悟） | 战斗/赶路/炼丹/休息时后台自动运转 |
| 离线收益 | 读档自动结算 | 需求 × 0.1%/现实小时 × 神通 | 上限 24 现实小时；进待领池（本层满留池等突破） |
| 顿悟 | 打坐期间自动 | 当前层需求 × 8%（凡界）/ 12%（仙界） | 每 4 时辰判定，概率 5% + 气运/1000 |
| 现实时钟 | 在线自动结算 | 在线 1.5 倍打坐速率 | 24 时上限 |

**关键约束（三重防刷）**：
1. **精力预算**——主动操作耗精力（每日行动量有限），打坐/休息循环自动衔接
2. **时间预算闸门**——游戏时间推进 ≤ 现实时间 × 10（`TimeGovernor` 在 advance_time 入口截断；闭关/离线走旁路，由独立速率控制）
3. **每日限额**——论道 5 场、历练 5 次、丹药 8 颗等（`daily` 计数器，跨日失效）

### 3. 突破与劫难

```
突破率 = 夹[5%, 98%](
    基础率 × (1 + 0.15%×(体质-10) + 0.10%×(悟性-10) + 0.05%×(气运-10))
    - 0.015% × 丹毒 + 丹药加成 + 功法加成 + 师门指点 )
```

- **小境界突破**：修为圆满即可，2 时辰冷却
- **大境界突破**：金丹起先渡天劫（独立判定，未渡中断突破）
- **仙劫分层**：天劫(凡界) → 仙劫 → 天衰之劫 → 道心劫 → 斩三尸 → 合道大劫（数据驱动名目）
- **心魔劫**：跨大境界突破成功后 30% 概率触发（金丹起），三选一——**正道**（稳，小增益）/ **歧途**（险，大增益+副作用）/ **超脱**（随机）——无绝对对错，玩家的道由玩家选
- 失败反噬温和：散去部分修为、轻伤，不掉境界

## 二、成长系统

### 1. 属性面板

```
最终值 = (base + Σadd) × Πmul        # 装备/功法/buff/门派/五要加成统一走 Modifier
```

- **战斗四维**：攻击 / 防御 / 身法 / 神识
- **天赋三维**：悟性（修炼速度+突破率）/ 根骨·体质（气血+突破率）/ 气运（顿悟+机缘+突破率）
- **负面计量**：丹毒（嗑药累积，压制突破率；调息与清毒丹可解）

### 2. 装备（六部位）

兵器 / 护甲 / 法宝 / 靴 / 佩饰 / 腰带，纯属性加成（简版，无强化/套装/耐久）。
穿脱即时生效，`equip` 无参查看清单。

### 3. 功法（多件装备 + 数据驱动效果）

- **六种效果类型**：attr_add（属性固定值，随境界缩放）/ attr_mul（属性百分比）/ 修炼速率 / 突破率 / 灵石加成 / 悟道（顿悟）
- **叠加规则**：attr_add 相加 / attr_mul 偏移相加（防指数爆炸）/ 突破率取 max / 速率类相加且封顶 60%
- **装备上限**随境界：2 件起，每 3 境界 +1，硬顶 5
- **熟练度**：修炼/专修累积，每 200 点 1 级（满 5 级 ×1.15/级）；等级由熟练度派生
- **品阶预算自检**：黄 32 / 玄 90 / 地 240 / 天 260 / 仙 480 效果点，超配会被测试拦住
- 修习功法即得**签名技能**

### 4. 技能（自动施法 + 策略预设）

- 四类：攻伐 / 疗伤 / 护体 / 回灵；消耗灵力比例、有冷却、有反噬
- 战斗中按策略自动施放：**保守**（稳，治疗护体优先）/ **均衡** / **激进**（快，输出优先，有战死风险）
- 三档策略最终境界一致，差别只在战斗过程——「更快 vs 更稳」交还玩家

## 三、资源与经济

### 灵石流转

| 来源 | 去向 |
|---|---|
| 猎妖掉落（约 14~600/场，随境界） | 修习功法（200~上万） |
| 坊市卖出（妖丹/材料/丹药） | 换购丹方（后期大口） |
| 门派日俸（15~60） | 入门费（100~800） |
| 天骄榜俸禄（第 1 名 500/日） | 洞府购置/扩建/维护 |
| 产业每日产出（灵田/商队等） | 产业增资 |
| 任务奖励 | 租灵室（50 贡献）、买装备 |

开局 200 灵石刻意卡的线：够修一门黄阶功法，不够买兵器——开局就要取舍。

### 炼丹（采集 → 炼制 → 嗑药正循环）

- `dan gather [时辰]`：采药，凶险处有稀有材料与遇险
- `dan learn <id>`：换购丹方（七张起步）
- `dan refine <id> [炉数]`：开炉，逐炉打印**成功率算式**与品阶判定
- 品阶：下品 70% / 中品 100% / 上品 140% 药效（程序派生，不手抄三份表）
- 造诣累积提升成功率；丹炉占法宝位；**丹毒**是泄压阀（无脑嗑药压制突破率）
- 400 日全资源推演：开炉 680 次、成丹率 92%、上品过半

### 坊市

- 价格每日浮动（夹在基准价 [0.5, 1.8] 倍），卖出 = 买入 × 0.6，买卖不耗时间
- 给灵石稳定消费出口与回流通道

## 四、修仙五要（法 · 财 · 侣 · 地 · 师）

全局 **BonusAggregator** 聚合：各来源实现 `collect_bonuses(agg)`，按效果类型叠加规则统一聚合，属性类注入一条 Modifier——加一层来源核心零改动。

| 要 | 系统 | 命令族 | 核心机制 |
|---|---|---|---|
| **法** | 功法 | `art [list\|learn\|equip\|unequip\|practice]` | 见上「功法」 |
| **财** | 产业 | `asset [list\|buy\|upgrade\|sell]` | 灵田/矿脉/丹铺/商队每日产出灵石+材料；增资升级线性成长；**付不起维护则停摆** |
| **侣** | 道侣 | `companion [list\|meet\|dual\|gift]` | 结识 4 位道友；双修（每日 3 次）换修为+情分；加成随情分 0.5→1.0 缩放；并肩对敌涨情分 |
| **地** | 洞府 + 地点 | `estate [list\|buy\|upgrade\|restore\|sell]`；`travel <地点>` | 洞府凡居→洞天修炼 +5%→+45%，**付不起维护则荒废**；地点灵气密度 1.0~3.0 直接乘修炼产出 |
| **师** | 门派 + 师长 | `sect [info\|list\|join\|masters\|apprentice\|mentor\|chamber\|stipend]` | 见下「门派」 |

实测递进（元婴圆满 + 宗门灵脉）：法 +26% → 加地 +55% → 加侣 +66% → 加师 +77%，每层耗时 -44%。

### 门派（七大门派）

| 门派 | 特色 | 门槛 |
|---|---|---|
| 青云宗 | 剑修正宗，守序安稳，灵力 +10% | 炼气，100 灵石 |
| 血煞门 | 以杀证道，攻伐 +15%，气运 -2 | 炼气，100 灵石 |
| 药王谷 | 丹道传家，丹毒消解快，体质 +2 | 炼气，100 灵石 |
| 天机阁 | 推演天机，悟性 +8%，日俸 40 | 筑基，500 灵石 |
| 剑冢 | 万剑埋冢，攻伐 +10%，攻伐登峰 | 筑基，800 灵石 |
| 万宝楼 | 以商入道，气运 +2，日俸 60 | 筑基，600 灵石 |

- **职位**：外门 → 内门 → 真传 → 长老（按贡献晋升），职位修炼场地加成 +2% → +12%
- **门派功法**：唯本门弟子可用贡献换购（如剑冢《万剑归宗》天阶攻伐）
- **师长**：3 位（突破/攻伐/灵石方向），拜师得稳定加成；`sect mentor` 请指点（贡献换一次性突破率 +5pp，每日一次）
- **灵室静修**：50 贡献租 24 时辰修炼 +30%（临时 buff 有时效）

## 五、战斗与挑战

### 1. 猎妖（hunt）与论道（duel）——两条独立曲线

| | hunt 猎妖 | duel 论道 |
|---|---|---|
| 判定 | 战斗数值（攻防身法+技能） | 悟性 + 神识对撼掷骰 |
| 产出 | 灵石/材料/装备（修为与打坐同量级 ×1.13） | 修为：胜 4% / 负 2% 需求（败也有得） |
| 档位 | weak/normal/elite/boss | 同 |
| 防刷 | 精力 | 精力 + 每日 5 场 |

战斗为回合制自动推演，技能按策略自动施放，濒死有护持不死（保底）。

### 2. 秘境（三座，线性层数推进）

| 秘境 | 层数 | 门槛 | 冷却 |
|---|---|---|---|
| 落云秘境 | 3 | 炼气 | 3 日 |
| 万兽深渊 | 5 | 筑基 | 5 日 |
| 太虚洞天 | 7 | 金丹 | 7 日 |

- `dungeon enter/next/flee/abandon`：深入触发层内抽签（战斗/宝箱/静室/机缘事件）
- 战败退层不死；进度可续（flee 保留）；通关冷却后重入
- 每层修为 1.5% 需求；宝箱 + 丹方是后期灵石主要出口

### 3. 天骄榜（排名竞技）

- 10 位 NPC 天骄按境界排第 1~10 名，玩家金丹以上自动入榜垫底
- `tianjiao fight <名次>`：挑战排名更高者，胜则**互换名次**
- 敌人按玩家属性 × power 系数等比缩放——赢了靠实力
- 每日按名次发俸禄（第 1 名 500 灵石 + 30% 需求修为，逐名递减）
- 防躺平：每日 3 战 + NPC 随游戏日缓慢成长

## 六、机缘与任务

### 剧情事件（数据驱动，data/events.json）

- `explore` 按地点机缘率触发（青石镇 45% ~ 万兽深渊 80%）
- 事件带条件（境界/地点/flag/物品/灵石）与选项前置；`choose N` 选择
- Web 版待决机缘时直接出选项按钮（移动端免打字）
- 部分事件触发战斗（battle 效果）/ 传功（art 效果）/ 送丹方（recipe 效果）

### 任务系统（data/quests.json）

- 开局自动接取可用任务；订阅战斗/事件/突破自动计数，**达成自动交付**
- 奖励按门派累声望；声望跨门槛解锁高阶任务（正循环：做任务 → 涨声望 → 解锁更肥任务）

## 七、挂机体系（养老定位核心）

| 方式 | 触发 | 收益 | 说明 |
|---|---|---|---|
| 闭关 | `idle` / Web 点「闭关打坐」 | = 手动打坐 | 自动打坐-休息循环，圆满自动停；不自动突破/嗑药（决策留玩家） |
| 被动周天 | 任何时间推进自动 | = 打坐 × 60% | 静默无日志，战斗赶路炼丹全兼容 |
| 离线 | 读档自动结算 | 需求 × 0.1%/现实小时 | 进**待领池**（本层满不浪费，突破后 claim）；幂等防重复 |
| 现实时钟 | 在线每 30s（Web 自动刷新） | 在线 1.5 倍 | 现实时间流逝 = 游戏内持续打坐 |

**数值节奏基线**（seed=2026 纯挂机）：150 日飞升人仙 → 1474 日混元 → ~3000 日混元圆满；仙界每境 130~190 日与凡界后期同构（顿悟按需求比例恒定）。全资源玩家（丹药/秘境/功法）明显更快。

## 十、玩一盘的典型节奏（新手指引草案）

1. **炼气期**：200 灵石二选一（黄阶功法 vs 攒钱）→ 闭关为主 + 探查碰机缘 → 落云秘境开荒
2. **筑基~金丹**：入门派（青云/血煞/药王）→ 采药炼丹起步 → 拜师 + 租灵室 → 天骄榜入榜
3. **元婴~渡劫**：洞府 + 产业铺开（财地）→ 双修道侣（侣）→ 门派功法（法）→ 渡劫前嗑丹 + 请指点
4. **飞升后**：仙界每境 130~190 日，仙劫名目层层递进——挂机养老，法无止境
